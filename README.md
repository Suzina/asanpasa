AsanPasa

AsanPasa is a full-stack order and payment management system built for small retail businesses.

Live Project: https://asanpasa.sujina-maharjan.com.np

Frontend: React 19 + Vite, Tailwind CSS 4, React Router 7, Axios, react-chartjs-2, react-data-table-component, react-select, @himal_bhattarai/nepali-datepicker
Backend: Node.js, Express.js, MySQL + Sequelize ORM, bcrypt, JSON Web Tokens, Multer
Deployment: GitHub Actions-auto-deploy to cPanel hosting on merge to main

Prerequisites
Node.js 18+
MySQL server running locally or accessible remotely
npm
